# Use explicit data migration and an isolated beta installation

The Flutter app will import existing Clock Rhythm schema-version-1 JSON backups with the current full-replacement semantics instead of reading Neutralino's private storage directly. The production Android application ID is `dev.wndls.clockrhythm`, while beta builds use `dev.wndls.clockrhythm.beta`; Windows likewise gives beta and production builds distinct package identity, local store, and automatic-start registration until feature parity is verified. The Flutter target is an independent Git repository, and the Neutralino repository remains an unmodified reference implementation throughout the port. This favors recoverable migration and safe rollback over an initially seamless in-place replacement, while preserving the existing rule that custom MP3 files are not carried inside backups.
