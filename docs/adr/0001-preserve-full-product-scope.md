# Preserve full product scope during the Flutter port

The Flutter port will reproduce all current user-facing Clock Rhythm capabilities—rhythm clock and controls, Todo and calendar, preferences for language, theme, sound, and automatic startup, tray-backed background operation, and JSON backup and restore—and remain compatible with version 1 backup files. Browser fallback behavior and the retired Google Tasks integration are excluded; this chooses behavioral and data continuity over a reduced clock-only rewrite so existing workflows and backups remain usable.
