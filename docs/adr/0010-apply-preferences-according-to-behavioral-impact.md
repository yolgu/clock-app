# Apply preferences according to behavioral impact

Clock Rhythm keeps the existing first-launch defaults: a 50-minute Focus Interval, a 10-minute Rest Interval, a 05:00–18:00 Daily Rhythm, Korean, the `current` theme, bundled default sound, and Windows automatic startup disabled. The rhythm settings remain expanded until their first successful save, and Android requests notification permission only when the user first tries to start a Rhythm Session.

Focus, rest, Daily Rhythm, and Windows automatic-start changes are drafts until an explicit save, while language, theme, sound choice, and volume apply immediately. Saving rhythm settings during an active session cancels obsolete future delivery and recomputes it from the new Daily Rhythm; a paused session stays paused, and Stop for Today remains stopped until the next start defined by the new configuration.

Mute suppresses only sound, not visible notifications. On Windows, unmuting restores the previous bundled or custom sound and its volume; zero percent volume remains distinct from Mute and produces only a warning. On Android, unmuting restores the bundled default sound.
