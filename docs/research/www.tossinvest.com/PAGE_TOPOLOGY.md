# Source page topology

## Desktop

1. Fixed 52-pixel top navigation with brand, destinations, search, and login.
2. Market summary region with compact chart and schedule panels.
3. Tab strip with an underline-style selected state.
4. Filter and segmented-control region.
5. Dense 44-pixel data table.
6. Product detail and community side panel.
7. Interest-list rail and compact remote-control rail.
8. Fixed 40-pixel bottom ticker.

The primary content and right rails form a desktop monitoring workspace. Several fixed layers use
very high z-index values.

## Narrow viewport

At 390 x 844 the page retains a 1024-pixel content width and horizontally overflows. Desktop rails
remain present. This behavior is unsuitable as a Clock Rhythm mobile-layout reference and is not
part of the implementation contract.
