# 백업과 앱 통합 검증

[전체 계획](../plan.md), 선행: [리듬과 플랫폼](P3.md)

Status: Done

목적: 모든 새 계약이 백업, 초기화와 복구까지 연결된 상태를 확인한다. 병렬 실행 없음.

경계: DB 형식, 백업 v1과 원자성, 기기별 상태 보상, 기존 오류 표시를 보존한다. 새 영구 검사나 배포는 없다.

파일: 앱 조립과 데이터 가져오기 갱신, 백업 실패 계약과 소비자, 관련 테스트와 기존 문서 참조를 변경한다.

위험: 가져오기 후 일부 화면의 오래된 상태, 이미 저장된 작업의 재실행, 원인 정보 손실. 복구: 관련 연결을 이전 동작과 함께 복원한다.

검증: 집중된 백업과 복구 테스트 후 전체 계획의 공통 검증 명령을 실행한다. 기존 문서에서 삭제된 파일을 참조하는 위치를 현재 책임 경계로 갱신한다. 생성 선언을 바꾸지 않는 한 전체 생성물 해시는 수행하지 않는다.

중간 확인: 미리듣기 실패와 저장 동시 진행 회귀, 백업 원인 보존의 실패를 먼저 확인하고 수정 후 관련 테스트 52개가 통과했다. 백업의 직접 저장소 참조는 공개 설정 서비스로 교체해 기존 경계 검사 223개 Dart 파일을 통과했다. 추가 집중 테스트 205개 통과.

최종 결과:

- Flutter 3.44.7, Dart 3.12.2, Xcode 26.6으로 검증했다.
- 형식 검사: 328개 파일, 변경 필요 없음, 종료 코드 0.
- 기존 기능 경계 검사: 223개 Dart 파일 통과, 종료 코드 0.
- 정적 분석: 문제 없음, 종료 코드 0.
- 전체 테스트: 623개 통과, 변경 전부터 존재한 8개 실패, 종료 코드 1.
- 실패 8개는 기준 이미지 비교 4개와 PowerShell 실행기 부재 4개다. 기준 이미지 실패의 실제 출력 4장은 변경 전 산출물과 파일 내용이 동일하다. 기준 이미지를 갱신하거나 테스트를 제외하지 않았다.
- 최종 macOS beta Debug 빌드 성공, 종료 코드 0.
- Android는 프로젝트가 요구하는 Gradle 9.1 배포본이 설치되어 있지 않아 빌드를 실행하지 않았다. Windows 네이티브 빌드와 세 플랫폼의 실기기 동작은 검증하지 않았다.
- 104개 Markdown 문서의 로컬 링크 339개를 확인했으며 끊어진 링크는 없다.
- 도메인 규칙, 데이터베이스 스키마와 저장 구현, 의존성 선언과 잠금 파일, 영구 검증 도구에는 변경이 없다.

회귀 확인:

- 미리듣기 실패가 진행 중인 설정 변경의 작업 상태를 해제하거나, 변경 완료가 그 오류 안내를 지우는 문제를 실패 테스트로 확인한 뒤 수정했다.
- 초기 조회 중 상태 소유자를 폐기할 때 날짜 구독이 남는 문제를 실패 테스트로 확인한 뒤 수정했다.
- 선택 날짜를 유지하면서 오늘 목록과 캘린더가 같은 변경 결과를 읽는 것을 확인했다.
- 백업 실패가 원인과 호출 정보를 보존하도록 기존 실패 테스트를 확장하고 실패 확인 후 통과시켰다.
