# [P1] 토큰 단일 진실 공급원과 기본 팔레트 변경

Purpose:

- 승인된 색상·간격·반경·타이포·모션 값을 기존 토큰과 테마 카탈로그의 권위 있는 선언에 반영한다.

Goal linkage:

- G1 토스형 시각 언어, G2 11개 테마 호환, G3 중복 없는 토큰 소유권.

Boundary mapping:

- Public interface: `ClockRhythmSpace`, `ClockRhythmRadius`, `ClockRhythmMotion`, `ClockRhythmLayout`, `ClockRhythmTypography`, `ThemeCatalog.resolve`.
- Implementation boundary: `lib/shared/ui/design_tokens.dart`, `lib/contexts/preferences/presentation/theme/theme_catalog.dart`.
- Out-of-scope adjacent behavior: `ThemePreference` ID와 직렬화 값, 비기본 테마 소스 스와치.
- Regression scenarios: 기존 백업 theme ID 복원, 플랫폼별 폰트, 200% 텍스트에서 compact 전환.

Files / Resources:

- Create: 없음.

Difficulty:

- 🟡 Medium

Risk:

- 기본 테마 스와치 변경이 theme ID 호환성 또는 비기본 테마 표시를 함께 바꿀 수 있다.

Rollback:

- 기본 `ThemeDefinition`의 여섯 색상과 토큰 상수를 이전 값으로 되돌리고 테스트 기대값을 복원한다.

Completion criteria:

- [ ] 기본 테마가 `#101013`, `#17171C`, `#F2F6FF`, `#3182F6`, `#57C28D`, `#F5445A`를 사용한다.
- [ ] 반경 4/8/10/12/999, 페이지 inset 16/20/24+, 카드 padding 16/20이 한 파일에서 정의된다.
- [ ] 열한 theme ID와 열 개 비기본 테마의 source swatch가 변경되지 않는다.

TDD / Validation steps:

1. Failing probe or failing test:
   - Command/check: 토큰·카탈로그 테스트에 승인값을 먼저 작성하고 `fvm flutter test test/shared/ui/design_tokens_test.dart test/contexts/preferences/presentation/theme/theme_catalog_test.dart` 실행.
   - Expected before implementation: 현재 18px 카드 반경, 28px wide padding, neon 기본 팔레트 기대값이 새 계약과 달라 실패한다.
2. Minimal implementation:
   - Action: 토큰 상수, 적응형 계산, 플랫폼 텍스트 역할, 기본 테마 스와치만 수정한다.
3. Passing verification:
   - Command/check: 동일한 두 테스트 파일 실행.
   - Expected after implementation: 승인값과 비기본 테마 보존 검사가 모두 통과한다.
4. Regression lock:
   - stable theme ID 순서와 비기본 source swatch 목록을 테스트가 고정한다.

Notes:

- 새 폰트나 패키지를 추가하지 않는다.
