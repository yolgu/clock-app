Difficulty:

- 🔴 High

Risk:

- 낮은 대비의 subtle boundary와 상태를 전달하는 3:1 control outline을 같은 역할로 합치면 접근성이 깨진다.

Rollback:

- 테마 파생 비율과 component theme 블록을 이전 구현으로 되돌리고 카드 프리미티브의 기존 decoration을 복원한다.

Completion criteria:

- [ ] surface blend가 4/9/13 percent 계층을 사용하고 subtle boundary와 control outline 역할이 분리된다.
- [ ] 일반 버튼과 입력은 8px, 카드는 10px, dialog는 12px 반경을 사용한다.
- [ ] 카드 drop shadow가 제거되고 모든 theme의 text/control 대비 검사가 통과한다.

TDD / Validation steps:

1. Failing probe or failing test:
   - Command/check: component-token과 card 테스트를 새 geometry·shadow·state 계약으로 먼저 변경해 실행한다.
   - Expected before implementation: 현재 pill 일반 버튼, 18px card, 12px input, drop shadow 때문에 실패한다.
2. Minimal implementation:
   - Action: 파생 색상과 WidgetState별 button/input/navigation/list/tooltip theme를 수정하고 card를 border-only panel로 바꾼다.
3. Passing verification:
   - Command/check: 테마 component·contrast, shared card, 접근성 contrast 테스트 실행.
   - Expected after implementation: 열한 theme의 contrast와 component geometry가 모두 통과한다.
4. Regression lock:
   - subtle decoration과 상태 전달 outline의 별도 역할 및 reduced-motion focus transition을 테스트가 고정한다.

Notes:
