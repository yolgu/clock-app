# [P5] 접근성·골든·회귀 계약 갱신

- [전체 계획](../plan.md)

Status:

- Done

Purpose:

- 승인된 시각 변경을 자동화된 접근성, geometry, widget, golden 증거로 고정한다.

Goal linkage:

- G2 테마 호환, G4 접근성·적응형 보존, G5 검증 가능한 결과.

Dependencies:

- depends_on: [[P3](P3.md), [P4](P4.md)]
- parallelizable: false

Required skills:

- [code-principles, client-ui-best-practices, verification-before-completion]

Boundary mapping:

- Public interface: 렌더링 결과, semantics, focus order, target size, text scaling.
- Implementation boundary: `test/`의 contract/widget/golden 테스트와 baseline PNG.
- Out-of-scope adjacent behavior: production source의 추가 기능 변경.
- Regression scenarios: current/Neon Dusk theme, compact/wide, ko/en, 200% text, Windows/Android navigation.

Files / Resources:

- Create: `test/app/presentation/windows_top_navigation_test.dart`가 P3에서 생성되지 않았다면 이 단계에서 누락을 차단한다.
- Modify: `test/shared/ui/design_tokens_test.dart`, theme tests, accessibility tests, `test/goldens/adaptive_layout_golden_test.dart`, 승인된 golden PNG.
- Test: complete `test/accessibility/`, targeted widget suites, golden suite.
- Delete: 이전 시각 계약만 설명하고 새 계약과 중복되는 assertion.

Difficulty:

- 🔴 High

Risk:

- 골든을 무검토로 갱신하면 overflow, 잘린 text, 약한 focus, 잘못된 hierarchy를 승인할 수 있다.

Rollback:

- 문제가 있는 golden과 해당 production slice를 함께 이전 상태로 되돌리고 해당 P-item만 재실행한다.

Completion criteria:

- [ ] 모든 changed token과 component state가 명시적 assertion을 가진다.
- [ ] compact/wide, ko/en, current/non-default theme golden을 사람이 직접 확인한다.
- [ ] contrast, 48dp target, focus, semantics, 200% text 테스트가 통과한다.

TDD / Validation steps:

1. Failing probe or failing test:
   - Command/check: production 변경 후 golden suite를 update 없이 실행한다.
   - Expected before implementation: 승인된 시각 변경 때문에 기존 baseline과 불일치한다.
2. Minimal implementation:
   - Action: 새 계약을 assert하도록 테스트를 보강하고 `--update-goldens`로 baseline을 재생성한다.
3. Passing verification:
   - Command/check: `fvm flutter test test/accessibility test/shared/ui test/contexts/preferences/presentation/theme test/goldens/adaptive_layout_golden_test.dart`.
   - Expected after implementation: 전체 대상 테스트가 통과하고 새 PNG에서 clipping/overlap이 없다.
4. Regression lock:
   - token 값, theme compatibility, navigation state, 핵심 화면 geometry를 독립 테스트와 golden이 함께 고정한다.

Notes:

- PNG 변경은 `view_image`로 원본 해상도에서 모두 확인한다.
