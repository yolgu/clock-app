# [P9] 테마·아이콘·기본음과 배포 고지 이관

Parent plan:

- [전체 계획](../plan.md)

Status:

- Done

Purpose:

- 기존 theme backup ID와 제품 자산을 유지하면서 재배포 가능한 palette, 명확한 provenance risk, 접근 가능한 derived color token을 제공합니다.

Goal linkage:

- schema v1의 11개 theme ID가 모두 유효해야 하고 `monokai-pro`는 proprietary palette/name 대신 Compatibility Theme `Neon Dusk`를 선택해야 합니다.
- 기존 `public/icon.png`와 `src/assets/CHIME14.mp3`를 Windows/Android 자산으로 사용하되 출처 미기록 위험을 숨기지 않아야 합니다.

Dependencies:

- depends_on: [[P1](P1.md), [P3](P3.md), [P8](P8.md)]
- parallelizable: true

Required skills:

- [client-ui-best-practices, code-principles]

Boundary mapping:

- Public interface: `ThemeCatalog`, stable `ThemePreference`→`ThemeData` mapping, `ThemeExtension`의 제품 color roles, bundled sound asset key가 presentation/platform adapter에 제공됩니다.
- Implementation boundary: source swatch와 license metadata는 catalog, Material semantic roles와 대비 보정은 theme builder, platform icon 변환은 build assets가 소유합니다.
- Out-of-scope adjacent behavior: theme ID 변경, 시스템/light theme, proprietary Monokai Pro 파일 재배포, custom MP3 선택은 다루지 않습니다.
- Regression scenarios: backup ID 삭제, palette 순서 변경, `Dracula Official` 표시, license 없는 palette를 검증됐다고 표기, derived foreground 저대비를 막습니다.

Files / Resources:

- Create: `lib/contexts/preferences/presentation/theme/{theme_catalog.dart,clock_rhythm_theme.dart,clock_rhythm_theme_extension.dart}`, `assets/images/icon.png`, `assets/audio/CHIME14.mp3`, Android mipmap/adaptive icon assets, `windows/runner/resources/app_icon.ico`, `ASSET_NOTICE.md`, `THIRD_PARTY_NOTICES.md`, `test/contexts/preferences/presentation/theme/{theme_catalog_test.dart,theme_contrast_test.dart}`, representative golden baselines.
- Modify: `pubspec.yaml` asset declarations, `android/app/src/main/AndroidManifest.xml`, `windows/runner/Runner.rc`, theme route placeholder.
- Test: exact ID set/order, all 11 token completeness, source swatches, Compatibility Theme display mapping, contrast/focus roles, asset load/decode smoke, launcher/icon packaging checks.
- Delete: Monokai Pro palette/name from distributable Flutter output. 다른 palette가 audit 실패하면 해당 proprietary/unverified swatch만 Compatibility Theme 방식으로 제거합니다.

Difficulty:

- 🔴 High

Risk:

- palette 이름이 공개 프로젝트와 같다는 이유만으로 license를 추정하면 release artifact가 재배포 조건을 위반할 수 있습니다.

Rollback:

- stable backup ID는 유지하고 표시명/palette mapping만 verified compatibility palette로 되돌립니다. asset 생성본은 source PNG로 다시 만들 수 있게 변환 절차와 해시를 notice에 기록합니다.

Completion criteria:

- [ ] exact IDs `current`, `tokyo-night`, `one-dark-pro`, `catppuccin-mocha`, `nord`, `dracula-official`, `gruvbox`, `monokai-pro`, `night-owl`, `synthwave-84`, `ayu-mirage-dark`가 모두 resolve됩니다.
- [ ] `monokai-pro`는 표시명 `Neon Dusk`와 독자적인 redistributable palette를 사용하고 Monokai Pro 이름·swatch를 artifact에 포함하지 않습니다.
- [ ] `dracula-official` ID는 유지하되 표시명은 `Dracula`이며, 다른 inherited palette의 공식 source/license와 고지 문구가 `THIRD_PARTY_NOTICES.md`에 있습니다.
- [ ] source swatch는 license-driven replacement 외에는 그대로이고 text/focus/disabled/error roles만 자동 대비를 위해 최소 조정됩니다.
- [ ] icon과 CHIME14는 source hash, 원본 경로, “저장소 내 provenance/license 기록 없음” 위험과 사용자 지시 하 재사용 사실을 `ASSET_NOTICE.md`에 기록합니다.

TDD / Validation steps:

1. Failing probe or failing test:
   - Command/check: theme ID/token/contrast tests와 `fvm flutter test test/contexts/preferences/presentation/theme`를 asset 복사 전에 실행합니다.
   - Expected before implementation: catalog·assets 부재와 proprietary mapping fixture 때문에 실패합니다.
2. Minimal implementation:
   - Action: 각 theme ID의 audited metadata와 color tokens를 작성하고 `ThemeData`/`ColorScheme`/`ThemeExtension`으로 변환합니다. source assets를 read-only 원본에서 복사해 platform sizes를 생성하고 notice를 작성합니다.
3. Passing verification:
   - Command/check: theme tests, golden tests, `fvm flutter build windows --debug`, `fvm flutter build apk --debug`, artifact asset inspection.
   - Expected after implementation: 11개 ID가 렌더링되고 icon/audio가 두 artifact에 포함되며 license/provenance 검사 체크리스트가 완결됩니다.
4. Regression lock:
   - exact ID snapshot, palette token snapshot, contrast test, notices manifest가 ID 손실·proprietary 회귀·asset 누락을 막습니다.

Notes:

- 시스템 theme와 light mode는 v1 범위 밖입니다.
- palette audit에서 출처나 재배포 권한을 확인할 수 없는 항목은 사용자에게 다시 묻지 않고 이미 합의한 stable-ID Compatibility Theme 규칙을 적용하고 notice에 기록합니다.
