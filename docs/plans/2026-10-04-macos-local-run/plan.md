# macOS 로컬 실행

## 목표와 범위

현재 Flutter 앱을 이 Mac에서 빌드하고 실행한다. 기존 Windows와 Android 기능, 데이터 모델과 UI를 유지한다. macOS용 runner와 서비스 조립만 추가하고 스토어 배포, 자동 시작, 메뉴 막대 상주는 이번 범위에서 제외한다.

## 설계

앱 시작점에서 macOS용 서비스 조립을 선택한다. macOS 화면은 기존 데스크톱 탐색을 재사용하며 Todo와 설정 저장은 기존 데이터베이스를 사용한다. 알림은 macOS 플러그인으로 전달하고, 기존 타이머와 오디오 처리 흐름을 재사용한다. macOS에서 제공하지 않는 자동 시작과 사용자 MP3 선택은 플랫폼 기능 설정에 반영한다.

## 검증과 회귀

- Flutter 3.44.7과 Dart 3.12.2를 사용한다.
- macOS 탐색에서 시계, 캘린더와 설정을 열 수 있는지 확인한다.
- 기존 Windows와 Android 화면 테스트를 유지한다.
- `fvm flutter analyze`, 관련 `fvm flutter test`, `fvm flutter build macos --release`를 실행한다.
- 빌드된 앱을 열고 시작 오류와 창 표시를 확인한다.

## 실행 환경과 한계

Xcode 26.6과 CocoaPods 1.16.2가 있다. 기존 기본 Flutter 3.27.4 대신 이 프로젝트에 고정된 SDK를 FVM에 추가한다. macOS의 알림과 소리는 앱이 실행 중일 때만 제공하며 잠자기와 앱 종료 후 예약 전달은 보장하지 않는다. 초기 상태에는 이전 Capacitor 파일이 Git 미추적 상태로 남아 있으며 변경하지 않는다.

## 상태

macOS release 빌드와 실제 앱 실행을 완료했다. 정적 분석과 아키텍처 검사는 통과했다. 전체 테스트의 통과 620개와 미통과 8개의 상세 원인, 산출물 위치는 [빌드와 실행 확인](items/P1.md)에 기록했다. 알림 배너와 잠자기 동작은 수동으로 검증하지 않았다.
