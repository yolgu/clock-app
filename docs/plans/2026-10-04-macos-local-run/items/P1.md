# macOS 빌드와 실행 확인

[전체 계획](../plan.md)

- Status: Done
- Purpose: 실행 가능한 앱을 만들고 실제 창을 연다.
- Dependencies: [실행 구성](P0.md). 순차 실행.
- Boundary: 로컬 빌드 산출물과 실제 앱 실행.
- Files: README.md, macos/ 설정, build/macos/ 산출물.
- Validation: Flutter 정적 분석, 관련 테스트, macOS release 빌드, 실제 앱 창과 시작 오류 확인.
- Risk: SDK나 플러그인 다운로드, Xcode 빌드, 네이티브 실행 문제.
- Rollback: 이번에 생성한 빌드 산출물만 제거할 수 있다. FVM의 기존 기본 SDK는 바꾸지 않는다.
- Completion: 앱 창에서 시계와 탐색 메뉴를 확인하고 실행 방법과 지원 한계를 기록한다.

검증 결과: macOS release 빌드 성공. Clock Rhythm Beta.app을 실행해 한국어 시계와 Todo 화면, 데스크톱 탐색과 테마 화면 표시를 확인했다. 앱 크기는 빌드 도구 기준 55.7 MB다. 정적 분석과 아키텍처 검사를 통과했다.

전체 테스트 결과는 620개 통과, 8개 실패다. 이미지 비교 4개가 0.46~1.77% 픽셀 차이로 실패했고 PowerShell 검사 4개는 pwsh 미설치로 실행하지 못했다. 기준 이미지나 기존 검사 규칙은 변경하지 않았다. 로그와 이미지 차이는 build/verification/에 보관한다.
